### 2. Online Mock Test Web Application
**Technologies:** HTML, CSS, JavaScript, Python Flask, MySQL, SMTP

A full-stack web-based examination platform designed to help students practice aptitude and technical exams in an interactive digital environment.

**Features:**
- **Student Registration System** — Secure registration with form validation
- **Concepts & Syllabus Module** — Learning materials for placement preparation
- **Mock Test Materials** — Downloadable PDFs for practice
- **Online Final Examinations** — Two-part final tests
  - Part 1: Aptitude & Reasoning questions
  - Part 2: English & Computer Terminology questions
- **Real-Time Result Evaluation** — Instant score calculation and feedback
- **Responsive User Interface** — Works seamlessly on desktop and mobile
- **Email Notifications** — SMTP integration for exam-related updates
- **Database Connectivity** — Secure storage of student details and answers
- **REST API Integration** — Backend API for data submission and retrieval

**Database Tables:**
- `users` — Student registration details
- `final_test1` — Aptitude test answers
- `final_test2` — English/Computer terminology answers

**Learning Outcomes:** Full-stack development, Flask backend, MySQL database management, SMTP integration, API handling, authentication workflows

### 4. Intelligent Traffic Congestion Prediction & Control using Vision and GNN
**Technologies:** Python, Computer Vision, Graph Neural Networks (GNN), Deep Learning

An AI-powered traffic congestion detection system combining Computer Vision and Graph Neural Networks to analyze real-time traffic patterns on road networks.

**Components:**
- **Computer Vision Module** — Processes traffic camera feeds
  - Vehicle detection and counting
  - Vehicle density estimation
  - Movement pattern analysis
  
- **Graph Neural Network Module** — Models road network topology
  - Road intersections as graph nodes
  - Connected roads as graph edges
  - Spatial relationship learning
  - Congestion signal propagation

**Capabilities:**
- Real-time congestion detection at individual points
- Cascading congestion pattern identification across entire road grids
- Predictive analysis for traffic flow optimization
- Smart city application

**Learning Outcomes:** Computer vision techniques, deep learning, graph neural networks, AI/ML applications, real-world smart city problems
